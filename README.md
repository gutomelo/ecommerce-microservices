# ecommerce-microservices

Projeto Backend de E-commerce com Microsserviços utilizando Spring Boot, Spring Cloud, AWS SNS/SQS e Saga por Coreografia.

O projeto vive em [`ecommerce-platform/`](ecommerce-platform/). Comece por [`ecommerce-platform/CLAUDE.md`](ecommerce-platform/CLAUDE.md) para a visão geral da arquitetura, stack, estrutura do monorepo e regras de desenvolvimento (`.claude/rules/`, `.claude/skills/`, `docs/`).
